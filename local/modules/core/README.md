# Модуль `core` для 1С-Битрикс

Базовый каркас модуля с библиотекой повторно используемых классов.

## Установка

1. Скопируйте каталог `core` в `/local/modules/`.
2. В административной части откройте Настройки → Настройки продукта →  Управление модулями `/bitrix/admin/module_admin.php`.
3. Найдите модуль `Core — библиотека вспомогательных классов` и установите его.

После установки модуль регистрируется в системе. Автозагрузка классов подключается через `include.php`.

## Использование

```php
use Core\User\User;
use Core\Support\Arr;
use Core\Cache\Cache;

    $name = User::getFullName($user ?? []);

    $value = Arr::get([
        'profile' => ['name' => 'Иван'],

    $items = Cache::remember(
        'my_unique_cache_key',
        3600,
        static function () {
            // Здесь запрос к ORM или другая тяжёлая операция.
            return [];
        },
        '/core/example/'
    );
}
```

## Принципы расширения

- Один класс — одна зона ответственности.
- Пространство имён `Core` соответствует каталогу `lib`.
- В `lib` размещаются классы библиотеки, а не код конкретного сайта.
- Не создавайте универсальный класс `Helper` со всеми методами подряд.
- Методы-обёртки над API Битрикс добавляйте только там, где они упрощают повторяющийся сценарий или стандартизируют поведение.
- Для кеширования с зависимостью от сущностей используйте тегированный кеш отдельно от простого `Data\Cache`.

Перед использованием проверьте совместимость с версией ядра проекта. Для продакшена также рекомендуется добавить тесты и зафиксировать минимальную поддерживаемую версию PHP/Битрикс.
