# Модуль `core` для 1С-Битрикс

Базовый каркас модуля с библиотекой классов расширяющих коробочные возможности 1С Битрикс.

## Установка

1. Скопируйте каталог `core` в `/local/modules/`.
2. В административной части откройте Настройки → Настройки продукта →  Управление модулями `/bitrix/admin/module_admin.php`.
3. Найдите модуль `Core — библиотека вспомогательных классов` и установите его.

После установки модуль регистрируется в системе. Автозагрузка классов подключается через `include.php` следующим образом:
```php
Loader::registerNamespace('Core', __DIR__ . '/lib');
```

Для начала использования инициализируйте модуль в init.php `local/php_interface/init.php`:
```php
use Bitrix\Main\Loader;

// Подключаем модуль core
if (Loader::includeModule('core')) {
    // Регистрируем обработчики событий
    \Core\EventHandlers\Base::register();
}
```
Регистрация обработчиков событий не является обязательной, но предоставляет дополнительные возможности при работа с Битрикс. Без их регистрации вы лишаетесь значительной части расширенных возможностей внутри системы.

Модуль готов к использованию.

## Принципы расширения

- Один класс — одна зона ответственности.
- Пространство имён `Core` соответствует каталогу `lib`.
- В `lib` размещаются классы библиотеки, а не код конкретного сайта.
- Не создавайте универсальный класс `Helper` со всеми методами подряд, в противном случае этот модуль вам не нужен.
- Методы-обёртки над API Битрикс добавляйте только там, где они упрощают повторяющийся сценарий или стандартизируют поведение.
- Для кеширования с зависимостью от сущностей используйте тегированный кеш отдельно от простого `Data\Cache`.

Перед использованием проверьте совместимость с версией ядра проекта. Для продакшена также рекомендуется добавить тесты и зафиксировать минимальную поддерживаемую версию PHP/Битрикс.
