# Business
Классы функционально расширяющие возможности сайта и панели администрирования
## IblockProperty
Коллекция дополнительных свойств инфоблока, отсутствующих в коробочной версии, но расширяющие возможности элементов инфоблока
- `DescriptionHTML` свойство HTML/текст
- `ElementsLists` свойство реализующее возможности привязки к элементам инфоблока в виде списка или автокомплита. Автокомплит реализован с использованием ajax `lib/ajax/Business/IblockProperty/elements_lists__element_search.php`

## Iblock
Класс для работы с инфоблоками и элементами инфоблока
### getIblockIdByCode()
Получает ID инфоблока по его символьному коду (`CODE`).

Метод выполняет ORM-запрос к таблице инфоблоков с использованием `Bitrix\Iblock\IblockTable`. Результат кешируется на время, указанное в константе `CACHE_TIME`.

Если инфоблок с указанным символьным кодом не найден или модуль `iblock` не подключён, метод возвращает `null`.

#### Сигнатура
```php
public static function getIblockIdByCode(string $code): ?int
```

#### Параметры
| Параметр | Тип | Описание |
|---|---|---|
| $code | string | Символьный код инфоблока |

#### Возвращаемое значение
| Тип | Описание |
|---|---|
| int | ID найденного инфоблока |
| null | Инфоблок не найден или модуль iblock не подключён |

#### Исключения
| Исключение | Описание |
|---|---|
| Bitrix\Main\ArgumentException | Ошибка аргумента ORM-запроса |
| Bitrix\Main\LoaderException | Ошибка подключения модуля |
| Bitrix\Main\ObjectPropertyException | Ошибка обращения к свойству ORM-сущности |
| Bitrix\Main\SystemException | Общая системная ошибка ORM |

#### Кеширование
| Параметр | Значение | Описание |
|---|---|---|
| Время кеширования | CACHE_TIME | Время хранения результата в секундах |
| Идентификатор кеша | iblock_id_by_code_ + md5($code) | Уникальный кеш для каждого символьного кода |
| Директория кеша | /core/iblock | Директория хранения кеша |

#### Пример использования
```php
$iblockId = IblockHelper::getIblockIdByCode('news');

if ($iblockId !== null) {
    // Инфоблок найден
}
```
### getIblockCodeById()
Получает символьный код инфоблока (`CODE`) по его ID.

Метод выполняет ORM-запрос к таблице инфоблоков с использованием `Bitrix\Iblock\IblockTable`. Результат кешируется на время, указанное в константе `CACHE_TIME`.

Если инфоблок с указанным ID не найден или модуль `iblock` не подключён, метод возвращает `null`.

### Сигнатура
```php
public static function getIblockCodeById(int $iblockId): ?string
```

#### Параметры
| Параметр | Тип | Описание |
|---|---|---|
| `$iblockId` | `int` | ID инфоблока |

#### Возвращаемое значение
| Тип | Описание |
|---|---|
| `string` | Символьный код найденного инфоблока |
| `null` | Инфоблок не найден или модуль `iblock` не подключён |

#### Исключения
| Исключение | Описание |
|---|---|
| `Bitrix\Main\ArgumentException` | Ошибка аргумента ORM-запроса |
| `Bitrix\Main\LoaderException` | Ошибка подключения модуля |
| `Bitrix\Main\ObjectPropertyException` | Ошибка обращения к свойству ORM-сущности |
| `Bitrix\Main\SystemException` | Общая системная ошибка ORM |

#### Кеширование
| Параметр | Значение | Описание |
|---|---|---|
| Время кеширования | `CACHE_TIME` | Время хранения результата в секундах |
| Идентификатор кеша | `iblock_code_by_id_` + `$iblockId` | Уникальный кеш для каждого ID инфоблока |
| Директория кеша | `/core/iblock` | Директория хранения кеша |

#### Пример использования
```php
$iblockCode = IblockHelper::getIblockCodeById(12);
```
Если метод вернул `null`, инфоблок не найден или модуль `iblock` не подключён.
