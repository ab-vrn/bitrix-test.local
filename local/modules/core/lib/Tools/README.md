# Tools
## Data
### replaceArrayParameters()
Рекурсивно заменяет значения элементов исходного массива на основании массива замен (`$replacements`).

Метод проходит по исходному массиву и проверяет наличие каждого ключа в массиве замен. Если ключ найден, его значение заменяется соответствующим значением из `$replacements`.

Если исходное значение и значение замены являются массивами, выполняется рекурсивная обработка вложенных элементов. При этом сохраняются элементы исходного массива, для которых не заданы замены.

Если значение замены не является массивом, исходное значение полностью заменяется новым.

Если один из переданных массивов пуст, метод возвращает исходный массив без изменений.

### Сигнатура

`public static function replaceArrayParameters(array $array, array $replacements): array`

### Параметры

| Параметр | Тип | Описание |
|---|---|---|
| `$array` | `array` | Исходный массив, значения которого необходимо заменить |
| `$replacements` | `array` | Массив с новыми значениями для замены |

### Возвращаемое значение

| Тип | Описание |
|---|---|
| `array` | Исходный массив с применёнными заменами |

### Особенности работы

- Поиск ключей для замены выполняется с помощью `array_key_exists()`.
- Вложенные массивы обрабатываются рекурсивно.
- Если оба значения являются массивами, заменяются только совпадающие ключи.
- Если значение замены не является массивом, оно полностью заменяет исходное значение.
- Элементы, для которых не заданы замены, сохраняются.
- Исходный массив не изменяется напрямую.
- Если массив замен пуст, возвращается исходный массив.

### Пример использования

```php
//  Исходный массив
$array = [
    'NAME' => 'Старое название',
    'ACTIVE' => 'N',
    'SETTINGS' => [
        'COLOR' => 'red',
        'SIZE' => 'large',
        'OPTIONS' => [
            'WIDTH' => 100,
            'HEIGHT' => 200,
        ],
    ],
];
//  Массив замены
$replacements = [
    'NAME' => 'Новое название',
    'SETTINGS' => [
        'COLOR' => 'blue',
        'OPTIONS' => [
            'WIDTH' => 300,
        ],
    ],
];

$result = ArrayHelper::replaceArrayParameters($array, $replacements);
//  Результат
[
    'NAME' => 'Новое название',
    'ACTIVE' => 'N',
    'SETTINGS' => [
        'COLOR' => 'blue',
        'SIZE' => 'large',
        'OPTIONS' => [
            'WIDTH' => 300,
            'HEIGHT' => 200,
        ],
    ],
]
```
